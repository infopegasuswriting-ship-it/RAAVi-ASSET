# Chapter practice and six-month capacity

Daily routine: one History session (16 answers) and one Geography session (12 answers), at separate study breaks. Each subject allows one start in its own rolling 24-hour window. Resuming uses the original start. Show a separate hours-and-minutes countdown for each subject. Present one question at a time. After a miss, give a short explanation and revisit the skill later through a different evidence task. A chapter tick describes this response only. Compare several fresh attempts before calling a chapter a strength.

Each chapter has 200 different cards. The standalone column includes the original reasoning, chronology and map questions plus the new recall prompts. Event ordering uses three dated events. Matching asks for one answer row covering two or three details from the chapter. The same source detail can recur in different cards. This inventory counts cards. It does not establish six months of independent factual coverage.

The selector blocks a previously reserved question family for 62 days. Among eligible cards it prioritises unseen prompts and spaces recently used component details when alternatives remain. Each subject has its own 24-hour start limit. A correct matching response earns one chapter tick. A wrong response identifies the question for review, but cannot by itself identify which component the student misunderstood.
