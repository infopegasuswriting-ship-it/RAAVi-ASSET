## Source register

Page numbers count from the PDF cover. The local page index contains extracted text for retrieval. The original page image takes precedence for maps, diagrams and damaged text. ### Geography

- **Climate** (inference). Western depressions bring winter precipitation. Uplift can enhance it over relief. [G1:27;G1:28]

## Running a chat round

Use practice.py start History or start Geography. Use next to resume, answer A/B/C/D or skip to record a response, and report to see chapter results. Display the map named by the facilitator. The end report lists chapters in book order with a tick for correct, a cross for incorrect and an explicit skipped label worth zero. The chat pilot stores one learner’s history locally.
